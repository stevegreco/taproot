Token Architecture

Design Token Reference

Three-tier token architecture: raw primitive values → context-aware semantic aliases → component-specific decisions.

Tier 1
Primitives
Raw design values with no semantic meaning. The source of truth. Never referenced directly in components.
color typography space radius shadow animation layout
→
Tier 2
Semantic
Intent-driven aliases (e.g. accent.default). Theme-aware: separate light & dark variants reference different primitives.
background foreground border accent status
→
Tier 3
Components
Specific decisions per component. Reference semantic tokens (and occasionally primitives for non-color values).
button card input alert badge
