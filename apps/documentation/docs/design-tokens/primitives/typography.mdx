---
title: Typography
description: Primitive font families, type sizes, weights, line heights, and letter spacing.
---

Typography primitives define the available type system scales. Combine them
through semantic or component tokens rather than styling product UI directly.

## Font families

| Token | CSS variable | Value |
| --- | --- | --- |
| `font.display` | `--primitives-font-display` | `'Lora', Georgia, serif` |
| `font.sans` | `--primitives-font-sans` | `'Source Sans 3', system-ui, -apple-system, sans-serif` |
| `font.mono` | `--primitives-font-mono` | `'JetBrains Mono', 'SF Mono', Menlo, monospace` |
