---
title: Primitive Tokens
description: Raw values for the design system's color, typography, spacing, shape, motion, and layout scales.
---

Primitive tokens are the raw values that establish the visual range of the
design system. They have no UI intent and provide the foundation for semantic
and component tokens.

:::note
Use primitive tokens when defining or extending the token system. In product
interfaces, prefer semantic or component tokens so intent and theming remain
explicit.
:::

## Reference

- [Color](/design-tokens/primitives/color) — palette scales and fixed colors
- [Typography](/design-tokens/primitives/typography) — families, sizes, weights, line heights, and tracking
- [Spacing](/design-tokens/primitives/spacing) — the layout spacing scale
- [Shape](/design-tokens/primitives/shape) — radii, shadows, and border widths
- [Motion](/design-tokens/primitives/motion) — easing curves and durations
- [Layout](/design-tokens/primitives/layout) — container width constraints

## Naming

Primitive CSS variables follow the token path:

```text
primitives.color.robRoy.500 → --primitives-color-rob-roy-500
primitives.space.4          → --primitives-space-4
primitives.radius.md        → --primitives-radius-md
```
