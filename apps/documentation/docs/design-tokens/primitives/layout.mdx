---
title: Layout
description: Primitive width constraints for prose, content, and application containers.
---

Layout primitives provide consistent maximum widths for common page and
content compositions.

| Token | CSS variable | Value |
| --- | --- | --- |
| `layout.narrow` | `--primitives-layout-narrow` | `640px` |
| `layout.prose` | `--primitives-layout-prose` | `720px` |
| `layout.wide` | `--primitives-layout-wide` | `960px` |
| `layout.xwide` | `--primitives-layout-xwide` | `1200px` |
| `layout.max` | `--primitives-layout-max` | `1440px` |
