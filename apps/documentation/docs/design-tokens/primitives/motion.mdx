---
title: Motion
description: Primitive easing curves and duration values for interface movement.
---

Motion primitives define the timing vocabulary used by transitions and
animations.

## Easing

| Token | CSS variable | Value |
| --- | --- | --- |
| `ease.out` | `--primitives-ease-out` | `cubic-bezier(0.22, 0.61, 0.36, 1)` |
| `ease.in` | `--primitives-ease-in` | `cubic-bezier(0.55, 0.06, 0.68, 0.19)` |
| `ease.inout` | `--primitives-ease-inout` | `cubic-bezier(0.65, 0.05, 0.36, 1)` |
| `ease.soft` | `--primitives-ease-soft` | `cubic-bezier(0.4, 0, 0.2, 1)` |

## Duration

| Token | CSS variable | Value |
| --- | --- | --- |
| `duration.fast` | `--primitives-duration-fast` | `140ms` |
| `duration.base` | `--primitives-duration-base` | `220ms` |
| `duration.slow` | `--primitives-duration-slow` | `360ms` |
| `duration.xslow` | `--primitives-duration-xslow` | `600ms` |
