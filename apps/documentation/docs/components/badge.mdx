<Badge variant="accent">Web component</Badge>

Badges label an item's state, category, or supporting metadata. They are
non-interactive; use a button or link when selecting the label should perform an
action.

## Variants

| Variant   | Use for                                 |
| --------- | --------------------------------------- |
| `default` | Neutral metadata or categorization      |
| `accent`  | Brand emphasis without implying status  |
| `success` | Successful or active states             |
| `danger`  | Failed, blocked, or destructive states  |
| `warning` | Conditions that need attention          |
| `info`    | Informational states and feature labels |

## Accessibility

- Keep labels short and meaningful.
- Do not rely on color alone; the text should communicate the state.
- Do not use a badge as an interactive control.
- The component intentionally sets no live-region role. If a badge changes in
  response to background activity and must be announced, apply the appropriate
  live-region semantics for that context.

The badge surface is available as `::part(badge)` for limited styling overrides.
