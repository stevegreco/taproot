<Badge variant="accent">React</Badge>

Buttons let people initiate an action. Use a clear, concise label that
describes what happens when the button is selected.

## Variants

<Tabs>
  <Tab title="Primary">
    Use for the most important action in a view. Prefer one primary button per
    action group.

    <CodeBlock
      lang="tsx"
      code={'<Button variant="primary">Save changes</Button>'}
    />
  </Tab>
  <Tab title="Secondary">
    Use for supporting actions that should remain visible without competing
    with the primary action.

    <CodeBlock
      lang="tsx"
      code={'<Button variant="secondary">Cancel</Button>'}
    />
  </Tab>
  <Tab title="Danger">
    Reserve for destructive or difficult-to-reverse actions.

    <CodeBlock
      lang="tsx"
      code={'<Button variant="danger">Delete project</Button>'}
    />
  </Tab>
</Tabs>

## Accessibility

- Use text that describes the action rather than a generic label such as
  “Click here.”
- Keep keyboard focus visible.
- Use `disabled` only when the action is unavailable and explain why nearby.
- Add an accessible name when an icon is the only visible content.
