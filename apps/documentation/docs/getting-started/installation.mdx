---
title: Installation
description: Add the design system token package and start using it in your project.
---

The package requires **Node.js 22.12 or newer** and works with pnpm, npm, yarn,
or Bun.

## Install and configure

<Steps>
  <Step title="Install the package">
    Add the design system to your project.

    <Tabs>
      <Tab title="pnpm">
        <CodeBlock
          lang="bash"
          code="pnpm add @stevegreco/design-system"
        />
      </Tab>
      <Tab title="npm">
        <CodeBlock
          lang="bash"
          code="npm install @stevegreco/design-system"
        />
      </Tab>
      <Tab title="yarn">
        <CodeBlock
          lang="bash"
          code="yarn add @stevegreco/design-system"
        />
      </Tab>
      <Tab title="Bun">
        <CodeBlock
          lang="bash"
          code="bun add @stevegreco/design-system"
        />
      </Tab>
    </Tabs>

  </Step>
  <Step title="Load the CSS tokens">
    The CSS entry point includes primitive values, semantic aliases, and
    published component aliases. Load it from your main stylesheet or
    application entry point.

    <Tabs>
      <Tab title="CSS">
        <CodeBlock
          lang="css"
          code={'@import "@stevegreco/design-system/css";'}
        />
      </Tab>
      <Tab title="JavaScript">
        <CodeBlock
          lang="ts"
          code={'import "@stevegreco/design-system/css";'}
        />
      </Tab>
    </Tabs>

  </Step>
  <Step title="Choose a color theme">
    Light values are applied to `:root` by default. Set
    `data-theme="dark"` on the root element to use the dark semantic values.
    Primitive tokens do not change between themes.

    <Tabs>
      <Tab title="HTML">
        <CodeBlock lang="html" code={'<html data-theme="dark">'} />
      </Tab>
      <Tab title="JavaScript">
        <CodeBlock
          lang="js"
          code={'document.documentElement.dataset.theme = "dark";'}
        />
      </Tab>
    </Tabs>

  </Step>
</Steps>

:::tip
For most applications, the CSS entry point is all you need.
:::

## Use tokens programmatically

Import individual token tiers as structured JSON for design tools, build
scripts, or Style Dictionary pipelines. Component JSON preserves references to
shared tokens; select a semantic theme when resolving those references.

<CodeBlock
  lang="ts"
  code={`import primitives from "@stevegreco/design-system/tokens/primitives";
import semanticLight from "@stevegreco/design-system/tokens/semantic-light";
import semanticDark from "@stevegreco/design-system/tokens/semantic-dark";
import components from "@stevegreco/design-system/tokens/components";`}
/>
