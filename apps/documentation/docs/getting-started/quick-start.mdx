## Install the package

```package-install
@stevegreco/design-system
```

## Load the CSS tokens

Import the generated stylesheet once near the root of your application:

```css app.css
@import "@stevegreco/design-system/css";
```

You can also import it from a JavaScript or TypeScript entry point:

```ts main.ts
import "@stevegreco/design-system/css";
```

## Use tokens by intent

Reference semantic tokens for general UI patterns. They automatically resolve
to the appropriate values for the active theme.

```css
.surface {
  color: var(--semantic-color-foreground-default);
  background: var(--semantic-color-background-raised);
  border: 1px solid var(--semantic-color-border-default);
  border-radius: var(--primitives-radius-md);
  padding: var(--primitives-space-4);
}
```

:::tip
If a component token exists, use it instead of assembling the component from
semantic or primitive values.
:::

## Enable dark mode

Set `data-theme="dark"` on the root element. Semantic aliases update without
changing component CSS.

```html
<html data-theme="dark">
```
