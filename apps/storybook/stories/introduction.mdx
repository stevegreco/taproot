# Taproot components

Stories for the web components in `@taproot-ds/web-components`, styled by the tokens in
`@taproot-ds/tokens`. Use the **Theme** toolbar to switch between light, dark, and the
system color scheme.

What each component is for, and the rules for using it, live in the spec records
(`pnpm spec get component.<name>`). These stories are a workbench for exploring states, not the
source of usage guidance.
