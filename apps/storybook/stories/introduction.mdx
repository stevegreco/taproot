# Ember & Sage components

Stories for the web components in `@stevegreco/design-system-components`, styled by the tokens in
`@stevegreco/design-system`. Use the **Theme** toolbar to switch between light, dark, and the
system color scheme.

What each component is for, and the rules for using it, live in the knowledge records
(`pnpm knowledge get component.<name>`) and on the documentation site. These stories are a
workbench for exploring states, not the source of usage guidance.
