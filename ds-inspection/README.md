# Design system inspections

Dated snapshots from the `ds-inspection` skill: `GARAGE.md` (the system profile), `reports/`,
`evidence/`, and `work-orders/`. Each one records the system as it was on its date. They are not
current guidance.

Inspections before the rename to Taproot ([ADR 0008](../docs/adr/0008-rename-to-taproot.md)) use
the old names: Ember & Sage is now Taproot, the `ds-spec` CLI is now `taproot`, and the
`@stevegreco/*` packages are now `@taproot-ds/*`. For current facts, query the spec with the
`taproot` CLI.
